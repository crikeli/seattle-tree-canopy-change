What this is

An independent estimate of how Seattle's tree canopy changed between 2013 and 2023, derived from real NAIP aerial imagery (not from an official canopy dataset - King County's own tree canopy layer only covers a single year, 2021, so there's nothing to directly diff). This demo computes canopy from raw 4-band NAIP imagery for both dates using the exact same method, then compares.

Finding: citywide tree canopy fell from an estimated 28.0% (2013) to 24.4% (2023) - a 3.6 percentage point loss over the decade, concentrated in the Central District / Capitol Hill / First Hill corridor, which saw substantial infill development and upzoning over that period.

Reading the map

The neighborhood change layer colors each of Seattle's 53 official Community Reporting Areas by canopy change (red = lost canopy, green = gained) - click any neighborhood for its exact 2013%, 2023%, and change. The NAIP 2013 / NAIP 2023 toggles load the actual aerial photos for each date (not loaded by default - each is about 45MB) so you can visually inspect where canopy actually disappeared, not just trust a color-coded number. Turn both on and slide their opacity to compare the same spot across the decade.

The two aerial images are hosted as Cloud-Optimized GeoTIFFs on Cloudflare R2 rather than committed to this repo. The page streams them directly via HTTP range requests, so toggling a year only pulls the tiles for whatever you're currently looking at instead of downloading the full ~45MB file.

Method, briefly (full detail + real data problems hit along the way in the notebook)

NDVI computed from NAIP's red and near-infrared bands, both years, aligned to one identical pixel grid (the two NAIP dates have different native resolutions - 1m in 2013, 0.6m in 2023 - so they don't align by default). A real systematic radiometric offset between the two acquisitions (different processing years apart) meant a single fixed NDVI threshold didn't work across both dates - fixed with per-year z-score normalization, with the canopy cutoff itself calibrated once against Seattle's own published ~28% citywide canopy figure.

Honest caveats

  • The canopy threshold is calibrated against a published external reference, not an absolute physical measurement - see the notebook for exactly how and why.
  • 5m analysis resolution (decimated from NAIP's native 0.6-1m) - fine for neighborhood-level change, not individual trees.
  • Seattle only, not all of King County.
  • Not an official assessment - see Seattle's own published 2016-2021 canopy study (cited in the notebook) for that.
